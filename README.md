# FERRI — Sitio web institucional

Sitio web estático y adaptable para Enfermeras Particulares FERRI.

## Publicar con GitHub Pages
1. Cree un repositorio público en GitHub, por ejemplo `ferri`.
2. Suba `index.html` a la raíz del repositorio.
3. Abra **Settings → Pages**.
4. En **Build and deployment**, elija **Deploy from a branch**.
5. Seleccione la rama `main` y la carpeta `/ (root)`, y guarde.
6. GitHub publicará el sitio en una dirección similar a `https://SU-USUARIO.github.io/ferri/`.
